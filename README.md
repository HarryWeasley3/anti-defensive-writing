# 反防御性写作

让 GPT 直接回答问题，交付清楚、干净的中文成品。

`anti-defensive-writing` 是一个由写作规则和改写示例组成的 Agent Skill，覆盖多余免责声明、反复限定、预先辩护、回避判断、纠错残留和工作过程混入成品等 10 类问题。

## 为什么使用这个 skill

你让 GPT 写番茄炒蛋，它擅自加了东坡肉。你要求撤销后，它删掉了配料，标题却变成“番茄炒蛋（无东坡肉版）”，正文还解释了三段为什么没有必要加肉。

同类问题也会出现在文章和项目文档中：内容修改了，辩护和纠错经过却留在成品里。读者需要的信息被挤到后面，还要额外理解作者经历过哪些争论。

这个 skill 提供一套可复用的判断标准：先完成当前任务，再检查每句话有没有帮助读者理解、判断或行动。纠正完成后，按最终需求组织成品，清除多余内容及其解释痕迹。

## GPT 的防御性写作表现

使用 GPT 起草和改写时，常见的问题包括：

- 普通问题先附上一段身份声明、风险提示和责任说明。
- 连续使用“可能”“通常”“在一定程度上”，却没有说明相关条件。
- 用户没有提出质疑，正文先补出假想争议，再解释和反驳。
- 用户要求选择，回答列出一串条件，最后仍然没有判断。
- 已经撤销的内容继续出现在标题、括号、注释和删除声明中。
- 正式文章中写入“本次已修正”“尚待核验”“后续补齐”等工作记录。

这些表达增加阅读负担，也会削弱结论。机械删除限定词同样会出问题，因此，技能要求保留影响结论和操作的具体条件，使判断强度与证据相符。

## 覆盖的 10 类问题

| 编号 | 问题 | 处理方式 |
|---|---|---|
| 1 | 多余免责声明 | 删除与当前理解、判断和行动无关的提醒。 |
| 2 | 过度限定 | 将模糊限定落实为具体条件、范围或缺少的信息。 |
| 3 | 预先辩护与无对象对比 | 清除假想质疑、无关否定和先否定再肯定的纠偏句式。 |
| 4 | 回避判断与过度平衡 | 先给判断，再按证据质量说明依据。 |
| 5 | 纠错后的残留 | 清除撤销内容的名称、别称、否定描述和解释。 |
| 6 | 句间关系不清 | 交代句间关系，先回答问题再展开。 |
| 7 | 修饰语嵌套过深 | 名词前的定语最多嵌套两层，超过上限就拆句。 |
| 8 | 抽象主语密集 | 同段内，抽象主语搭配动作动词最多两句，随后改用具体的人、事物或场景。 |
| 9 | 中文与标点不统一 | 中文使用全角标点，数字、代码、网址及路径保留标准格式。 |
| 10 | 工作过程混入成品 | 正式文档呈现当前事实、功能、结果和操作，清除工作记录、核验过程、编辑取舍及自动追加的计划。 |

第 5 类检查标题、正文、注释及附属交付物，也检查仍在回应旧争论的语义残留。

第 10 类要求先处理事实问题。无法确定的数据及相关结论不进入成品；影响必要交付的信息缺口在对话中解决。删除核验提示后，不能继续把未确定的内容写成事实。

## 适用场景与执行原则

适用于中文问答、文章、报告、产品介绍、README、架构说明、操作指南、代码注释和 PR 文案，也适合在用户纠正 Agent 后整理最终交付。

改写时保留事实、数字、证据范围和作者立场。技能通过指令与示例影响输出，实际效果取决于模型是否遵循规则。

用户明确要求工作日志、审计报告、变更记录或计划时，按对应任务撰写；这些内容不自动进入其他正式文档。

## 安装

### 准备文件

下载并解压本仓库。安装的是包含 `SKILL.md` 的 `anti-defensive-writing` 文件夹。

技能本身只包含指令、示例和界面信息，无须安装 Python 包、配置 API 密钥或运行脚本。

### Codex 个人安装

将技能目录放入个人目录的 `.agents/skills/`，即可跨项目使用。以下命令在下载并解压后的仓库根目录执行。

Windows PowerShell：

```powershell
$skillRoot = Join-Path $env:USERPROFILE '.agents\skills'
New-Item -ItemType Directory -Path $skillRoot -Force | Out-Null
Copy-Item -LiteralPath '.\anti-defensive-writing' -Destination $skillRoot -Recurse
```

macOS 或 Linux：

```bash
mkdir -p "$HOME/.agents/skills"
cp -R ./anti-defensive-writing "$HOME/.agents/skills/"
```

### Codex 项目内安装

只在一个项目中使用时，将技能文件夹放入目标项目的 `.agents/skills/`，并随项目提交。

```text
目标项目/
└── .agents/skills/anti-defensive-writing/
    ├── SKILL.md
    ├── agents/openai.yaml
    └── references/examples.md
```

两种范围选择其一。已有安装时更新原目录，避免重复安装同名技能。Codex 会自动检测技能变更；没有显示时重启 Codex。目录和加载方式见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

## 使用方法

在 Codex 中显式调用 `$anti-defensive-writing`，随后给出任务或原文，也可以从技能选择器中选择。Codex 还可以根据任务与描述的匹配情况自动选用技能，机制见 [官方说明](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills)。

起草文章：

```text
$anti-defensive-writing
写一份面向烹饪新手的两人份番茄炒蛋食谱，说明食材、步骤和操作要点。
```

改写原文：

```text
$anti-defensive-writing
改写下面的文章，保留事实、数字和原意，直接交付修改后的正文。

［在这里粘贴原文］
```

整理交付文档：

```text
$anti-defensive-writing
根据当前实现整理使用说明，说明现有功能和操作步骤。
```

默认交付可以直接使用的成品。需要问题标注或前后对照时，明确提出“按 10 类规则标注问题，再给出完整改写稿”。

## 检查修改效果

- 开头回应任务，要求判断时给出结论。
- 每个限定都有用途，结论符合证据。
- 句间关系清楚，长名词已经拆开。
- 撤销内容及其解释从各处清除。
- 正文围绕读者需求展开，不承担修改和核验进度汇报。

## 完整对照：一盘番茄炒蛋

### 使用场景

虚构的社区厨房要为新手编写两人份番茄炒蛋食谱，要求鸡蛋成块、番茄有汁，并明确给出食材和操作步骤。

食谱采用 2 个中等大小的番茄、3 个鸡蛋、10 mL 食用油和 2 g 盐。其中，0.5 g 盐加入蛋液，1.5 g 盐用于炒番茄。

Agent 起初擅自加入东坡肉。用户要求撤销后，请它完成食谱定稿。第一版刻意集中 10 类错误，括号中标明问题；第二版展示预期的成品写法。

### 使用 skill 前

#### 番茄炒蛋（无东坡肉版）

（错误 5：标题保留已经撤销的内容。）

本文仅供一般烹饪参考，不构成专业烹饪或营养建议。不同家庭的锅具、食材和偏好不同，读者应结合情况审慎判断，本文无法保证每次都能做出相同效果。

（错误 1：普通食谱开头附带整段无关免责声明。）

本文先介绍食材，再讨论制作方式，接着解释本轮调整，最后列出待核对的细节和后续试做安排。

（错误 10：把写作提纲、修改记录和工作安排写进食谱。）

这份食谱围绕家庭两人份番茄成熟度差异适配鸡蛋凝固程度控制方案展开，希望帮助新手探索合适的操作方式。

（错误 7：多层修饰语和连续名词掩盖实际要做的事。）

一般而言，鸡蛋可能通常可以考虑先炒一下，但是否应该这样做，也不一定能够脱离具体情况判断。番茄则或许可以根据实际状态适当炒到某种程度。

（错误 2：反复限定，没有说明可观察的操作条件。）

火候机制驱动了风味释放。翻炒框架抓住了口感关键。食材协同体系激活了餐桌体验。

（错误 8：同段连续三句使用抽象主语和动作动词，缺少具体操作。）

先把鸡蛋炒成块盛出。两人份应该准备 2 个中等大小的番茄。

（错误 6：从烹饪步骤跳回备料，读者需要自行整理顺序。）

本食谱还使用 3 个鸡蛋、10 mL 油和 2 g 盐。鸡蛋打散后加入 0.5 g 盐，用 6 mL 油炒成块盛出。再用余下的 4 mL 油炒番茄，出汁后加入 1.5 g 盐，最后倒回鸡蛋翻匀至热透。

用户希望鸡蛋成块，分开炒更容易控制成形程度。不过，一起下锅也比较省事，两种做法都有道理，因此很难推荐哪一种。

（错误 4：没有围绕用户已经明确的目标作出选择。）

需要强调的是，推荐先炒鸡蛋，并不意味着其他炒法没有价值，更不能据此否定所有家庭的做法，也不应将这份食谱理解为对全部家常菜的统一规定。

（错误 3：围绕未被提出的争议进行辩护。）

本轮已把盐从 3 g 改为 2 g，并核对了鸡蛋数量。番茄品种记录尚待补齐，后续需要进行口味测试，并比较不同锅具的影响。

（错误 10：正文汇报纠错动作、核验状态和未来计划。）

东坡肉已经删除，因为用户只要求番茄炒蛋。这里再次说明，本版没有加入东坡肉，也没有必要额外增加肉类配料。

（错误 5：撤销完成后，仍反复提及相关内容并解释删除原因。）

Final advice: 这道菜适合搭配 rice, 具体做法仍需综合考虑.

（错误 9：无必要地夹用英文，中文语句使用半角标点。）

### 使用 skill 后

#### 番茄炒蛋

这份食谱供两人食用。先把鸡蛋炒成块，再炒番茄，最后合炒，可以让蛋块保持成形，同时裹上番茄的汤汁。

##### 食材

- 中等大小的番茄 2 个。
- 鸡蛋 3 个。
- 食用油 10 mL。
- 盐 2 g。

##### 做法

先准备食材。番茄洗净后切成小块；鸡蛋打入碗中，加入 0.5 g 盐，搅打均匀。

食材备好后，开始炒鸡蛋。锅中倒入 6 mL 油，油热后加入蛋液，用锅铲轻推，让蛋液凝固成块，随后盛出。

接着炒番茄。锅中加入余下的 4 mL 油，倒入番茄翻炒。等番茄变软、炒出汤汁后，加入余下的 1.5 g 盐。

番茄出汁后倒回鸡蛋，轻轻翻拌，让蛋块裹上汤汁。所有食材热透后，即可盛盘。

##### 操作要点

鸡蛋成块后先盛出，可以减少它持续受热的时间。番茄单独炒至出汁后再合炒，汤汁更容易裹在蛋块上。

如果番茄炒后锅底发干，加入 1 汤匙水，帮助炒出汤汁。倒回鸡蛋后轻轻翻拌，保留蛋块形状。

炒好的番茄炒蛋适合搭配米饭。盛盘时把汤汁一起倒入，让蛋块和米饭都能裹上番茄的酸甜味。
